# TASK-LICENSES-01 — Лицензии и авторы

Добавлен постоянный публичный раздел `/licenses`. Ссылка «Лицензии и авторы» находится под панелью главной страницы, а пункт © с полным названием в подсказке — в верхнем меню лобби. Он доступен ведущему и обычному игроку. Из лобби раздел открывается в новой вкладке, сохраняя игровую сцену.

Используемые и запланированные ресурсы показаны отдельно. Пустой список используемых ресурсов означает, что записи ещё не добавлены, а не отсутствие сторонних ресурсов в проекте. Полная инвентаризация существующих ассетов в эту задачу не входила; неподтверждённые авторы и лицензии не добавлялись.

## Первый ресурс

В `app/data/asset_credits.json` внесён Modular Road Bridge, автор VectorMan, статус `planned`. Изменений нет, интеграция не выполнялась.

24.10.2026 через [публичный API Sketchfab](https://api.sketchfab.com/v3/models/f14e768fde1d4d4d9ef8886ca55cfc03) подтверждены название, автор, канонический URL модели и точная версия лицензии: API вернул `license.url = http://creativecommons.org/licenses/by/4.0/`. В реестре используется соответствующий HTTPS-адрес [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Как добавить ресурс

1. Добавить объект в массив `app/data/asset_credits.json` (UTF-8, корректный JSON).
2. Указать уникальный стабильный `id`, `name`, `author`, `category`, `source_url`, `license`, `license_url`, `modifications`, `status`. Для ссылок использовать полные HTTP(S)-адреса оригинального источника и условий лицензии.
3. Выбрать `status: "planned"` для будущей интеграции либо `"in_use"` для фактически используемого ресурса. После TASK-ASSET-02 у моста нужно изменить статус и описать реальные изменения, сохранив его `id`.
4. Указывать только подтверждённые данные. Неизвестные значения можно хранить как `null`: интерфейс покажет, что сведения отсутствуют. Фраза «изменений нет» допустима только при известном отсутствии изменений.
5. Обновить `/licenses`: JSON читается заново при каждом запросе. HTML, JavaScript, БД и перезапуск процесса для изменения записей не нужны; файл должен попасть на сервер при развёртывании.

Поле `license` не ограничено CC BY: допустимы CC0 и другие названия с соответствующим `license_url`. Для CC BY карточка выводит название, автора, источник, ссылку на условия и сведения об изменениях. Требования другой лицензии нужно проверять по её собственным условиям; при необходимости сохранять дополнительные уведомления правообладателя в сведениях о ресурсе. Не следует описывать указание авторства как одобрение или официальную поддержку VTT.
