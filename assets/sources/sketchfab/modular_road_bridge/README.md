# Modular Road Bridge

- Автор: **VectorMan** (https://sketchfab.com/ankit.baing.ab).
- Оригинал: https://sketchfab.com/3d-models/modular-road-bridge-f14e768fde1d4d4d9ef8886ca55cfc03.
- Лицензия в метаданных GLB: **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/.
- `original.glb` — предоставленный пользователем экспорт; авторские метаданные сохранены внутри.
- SHA256: `442e7c162ea75ef41e215d70328a9f420523aea275252056c27b9dc5622557d0`.
- `inspection.json` — результат разбора геометрии и подготовки.

Подготовка выполняется `scripts/build_road_bridge.py`. Изменения: нормализация осей, масштаба и начала координат, запекание преобразований, удаление служебных узлов, объединение одинаковых материалов, отделение балки/столбов и переиспользование геометрии колонны. Исходные изображения сохраняются байт в байт в подготовленном GLB. Новой Mask-карты нет.

Описание размещения, адаптации материалов и проверок: [отчёт интеграции](../../../../docs/bridge-asset-audit.md). Указание авторства не является утверждением об одобрении VTT автором.
